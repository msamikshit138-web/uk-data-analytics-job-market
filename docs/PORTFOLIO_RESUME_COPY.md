## Resume project entry

### UK Data Analytics Job Market Analysis
**Python | SQL | Pandas | REST API | Power BI | Git/GitHub**

- Built a reproducible analytics pipeline combining public UK job-posting indices with optional live analytics-vacancy data.
- Used Python to automate ingestion, cleaning, role classification, salary preparation and technical-skill extraction.
- Developed SQL queries to analyse role demand, salary transparency, geography, skill combinations and employer activity.
- Designed a four-page Power BI reporting model covering market trends, skill demand, salary intelligence and geographic hiring patterns.
- Added automated tests and GitHub Actions CI to improve reproducibility and code quality.
